# 回响 · 泰拉 —— 明日方舟主题心理测试(galgame 框架)

一个纯 HTML/CSS/JS、无框架、可直接部署到 GitHub Pages 的交互测试骨架。
当前是**可运行的框架 + 占位内容**,核心机制已全部跑通,后续只需往 `data.js` 灌内容。

## 文件结构

| 文件 | 职责 | 后期是否需要改 |
|------|------|----------------|
| `index.html` | 页面骨架 + 全部 CSS(美术风格) | 一般不动;调美术时改 |
| `ui.js` | 呈现层:逐字浮现、白光剪影、结局显影、meta 层 | 一般不动 |
| `engine.js` | 逻辑引擎:状态机、维度打分、收敛算法、彩蛋触发 | 一般不动 |
| `data.js` | **全部内容**:维度、剧情、题目、干员、结局文案 | **只改这个** |

数据与逻辑彻底分离。补内容 = 编辑 `data.js`,不碰引擎。

## 已跑通的核心机制

1. **性格维度引擎**:7 维坐标(理想/现实、秩序/自由、牺牲/自保、宽恕/复仇、守护/征服、理性/炽情、群体/孤高)。每道三观题在若干轴加减分,累积成测试者坐标。
2. **剧情硬分支**:阵营、关系性质等 `branch` 节点切换剧情线并圈定结果池。
3. **收敛算法**:先按池标签 + 关系标签过滤候选,再在候选内取与测试者坐标加权距离最近的干员。全干员池 → 唯一结果。
4. **白光剪影母题**:那个"要找的人"始终是场景中央的白色光影,`silhouette` 值(0~1)控制清晰度,随收敛推进从模糊到接近显形。
5. **结局显影**:白光爆闪 → 干员名字浮现 → 重逢文案逐行浮现,冷底暖金。
6. **普瑞塞斯 meta 彩蛋**:累计 meta 计数达阈值,正常结局被替换,普瑞塞斯打破第四面墙,以独立青蓝配色 + SYSTEM OVERRIDE 界面出现在所有 UI 之前。

## 如何扩充内容(改 data.js)

### 加维度题(三观题 / 突发事件)
在 `STORY` 里加 `type:"moral"` 节点,选项的 `scores` 决定在哪些轴打分:
```js
your_node_key: {
  type: "moral", silhouette: 0.5, bg: "#101d2e",
  text: ["情境描述第一行", "第二行"],
  options: [
    { text: "选项", next: "下一节点key", scores: { guard:-0.4, reason:0.3 } },
  ],
}
```

### 加剧情硬分支(切池子 / 定关系)
`type:"branch"`,选项带 `pool`(圈定结果池)或 `relation`(确立关系):
```js
{ text:"选项", next:"...", pool:"rhodes", relation:"comrade", scores:{...} }
```

### 加干员
往 `OPERATORS` 数组加对象:
```js
{
  name:"干员名", tier:"core",           // core=完整重逢, daily=一句日常
  pools:["rhodes"], relations:["comrade"],
  coord:{ ideal:-0.5, order:0.2, ... }, // 7 维人格坐标,-1~+1
  ending:["重逢文案第一段","第二段"],   // daily 写一句即可
}
```
**全干员覆盖策略**:核心干员(约100-150)写完整 `ending` 并标 `tier:"core"`;
其余干员标 `tier:"daily"`,`ending` 写一句日常向即可。收敛算法对两类一视同仁。

### 调普瑞塞斯彩蛋
改 `PROSECTS.threshold`(触发所需 meta 计数)和 `lines`(她的台词)。
给任意选项加 `meta:true` 即让该选项 +1 meta 计数(通常是"打破沉浸/怀疑世界"类选项)。

## 本地预览

```bash
# 任选其一
python3 -m http.server 8000     # 然后打开 http://localhost:8000
# 或直接双击 index.html 用浏览器打开
```

## 部署到 GitHub Pages

把这四个文件(+ assets/)推到仓库,仓库 Settings → Pages → 选 main 分支根目录即可。
无需构建步骤,纯静态。不依赖 Hugo。
